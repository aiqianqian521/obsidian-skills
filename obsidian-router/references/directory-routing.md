# Directory Routing

在 distill 写入前，用以下判决规则确定目标目录。先检查正向指标（✅ YES），再检查反向指标（❌ NO）。如同时命中多个目录，按优先级链裁决。

## 活跃目录判决规则

### 05_概念/ — 概念和模型

| 方向 | 条件 | 判断方法 |
|------|------|---------|
| ✅ YES | 定义了一个可复用的思维模型、术语或框架 | 标题是名词短语（"XX模式""XX模型""XX架构"）；内容回答"是什么" |
| ✅ YES | 主要篇幅 ≥70% 在解释概念而非列步骤 | 统计段落：解释性段落 vs 编号步骤段落 |
| ❌ NO | 内容是带编号的步骤化操作（≥3 步） | → 去 `09_可复用流程/` |
| ❌ NO | 记录了具体选择 A-vs-B 及取舍理由 | → 去 `06_决策/` |
| ❌ NO | 描述了具体 bug/问题 + 修复方案 + 日期 | → 去 `10_问题解决/` |

### 06_决策/ — 选择和权衡

| 方向 | 条件 | 判断方法 |
|------|------|---------|
| ✅ YES | 记录了具体决策（选了 A 不选 B） | 内容包含"选择 X 而非 Y"或"决定使用" |
| ✅ YES | 包含 alternatives（备选方案列表） | 明确列出了 2+ 个备选并做了对比 |
| ✅ YES | 包含 tradeoffs（明确写的取舍理由） | 内容包含"代价""风险""放弃" |
| ❌ NO | 内容是通用方法论，无具体决策场景 | → 去 `05_概念/` |
| ❌ NO | 内容是纯操作步骤 | → 去 `09_可复用流程/` |

### 09_可复用流程/ — 操作手册（playbook）

| 方向 | 条件 | 判断方法 |
|------|------|---------|
| ✅ YES | 内容是步骤化的，≥3 个有序步骤 | 计数编号步骤（1. 2. 3. / Step 1 / L1 L2 L3） |
| ✅ YES | 回答"怎么做"，带操作指令 | 使用祈使句或操作动词（"读取""创建""运行""检查"） |
| ✅ YES | 包含 Inputs / Steps / Outputs 或等价结构 | 检查是否有 When To Use / Steps / Outputs / Failure Modes 等段落 |
| ❌ NO | 内容是一次性修复记录（symptom + solution + date） | → 去 `10_问题解决/` |
| ❌ NO | 纯概念解释，0 个操作步骤 | → 去 `05_概念/` |

### 10_问题解决/ — 问题和修复

| 方向 | 条件 | 判断方法 |
|------|------|---------|
| ✅ YES | 描述了具体 bug/问题 + 修复方案 | 包含 symptom/根因/solution 中至少两项 |
| ✅ YES | 带有具体日期和解决状态（solved/open） | frontmatter 有 `date` + `status: solved|open` |
| ✅ YES | 内容是一次性的、与特定事件绑定的 | 引用了具体的 source note 或会话 |
| ❌ NO | 内容是通用方法，不绑定具体事件 | → 去 `05_概念/` 或 `09_可复用流程/` |
| ❌ NO | 无具体问题场景描述 | → 去 `05_概念/` |

## 优先级链

当内容同时命中多个目录时，按以下顺序裁决（数字越小优先级越高）：

1. **有具体日期 + symptom + solution** → 优先 `10_问题解决/`
2. **步骤化 ≥3 步 + 带编号** → 优先 `09_可复用流程/`
3. **有 alternatives + tradeoffs** → 优先 `06_决策/`
4. **定义模型/术语/框架** → 优先 `05_概念/`
5. 以上都不匹配 → 以 `note-schema.md` 的 `type` frontmatter 为准选择对应目录
6. type 也无法唯一确定 → `pause`，列出候选目录（最多 2 个）让用户选择，**不得默认放根目录**

## 边界案例

| 情况 | 裁决 |
|------|------|
| 内容只有理论解释，无操作步骤 | `05_概念/` |
| 有操作步骤但 <3 步 | `05_概念/`（不算 playbook） |
| 修复记录被提炼为通用方法 | 重新判决——有 ≥3 步骤 → `09_可复用流程/`；纯解释 → `05_概念/` |
| 两个目录优先级相同 | 以用户知识库已有的目录分布为准（同类内容放哪就放哪）；无先例则 `pause` |
| 根目录 | **不写内容笔记**。只放 `_index.md`。内容笔记必须进子目录 |
